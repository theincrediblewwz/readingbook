## 定义：偶数

整数 n 称为偶数，是指存在整数 k，使 n = 2k。

## 命题：两个偶数之和是偶数

若 a 与 b 是偶数，则存在整数 r、s，使 a = 2r，b = 2s。
于是 a + b = 2(r + s)。因为 r + s 是整数，所以 a + b 是偶数。

这里的前提是 a、b 为整数并且都为偶数。不能把“任意两个实数之和是偶数”当作这个命题的结论。
