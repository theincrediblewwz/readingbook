# ReadingBook

一本书，一个安静的阅读空间。ReadingBook 把原文、笔记和 AI 帮助放在一起，让你边读边问，也能随时回到原书核对。

[下载 Mac 版](https://github.com/theincrediblewwz/readingbook/releases/latest) · [更新历史](CHANGELOG.md) · [数据存储说明](数据存储说明.md)

## 可以做什么

- **读自己的书**：导入 PDF、EPUB 和文本，使用目录、可调大小的缩略图、书签与原文查找定位内容；选择连续阅读、单页或纸书翻页，也可切换柔和纸张。
- **留下自己的理解**：写 Markdown 笔记，按文件夹收纳；把笔记绑定到具体位置，就能作为页边便签显示。句子也可留下直线、波浪下划线或独立荧光标记；便签可选四种纸色，阅读操作支持 ⌘Z 撤销。
- **边读边问**：伴读解释当前内容，对话可以继续追问；两者独立工作。回答可收起、存为笔记或归档，需要时再引用回来。
- **逐步分析长书**：选择页码或章节开展智能阅读。默认沿用兼容成果、继续补齐缺口；补充或重新分析可明确选择，旧成果保留。
- **用不同方式整理线索**：阅读途中可以直接对 AI 说“帮我理理这些人物的关系”，让它选择、复用或加入关系图谱、时间轴、地图等组件，也能把现有元件组合成联动视图。需要新增分析时，选择“功能协作”并允许这次整理；用“读到这里”回顾前文，避免自动读取后续章节。
- **把线索放在一起**：可以说“把人物关系、相关事件和我的笔记放在一起”。工作台选择一个人物时，介绍、关系、事件与关联笔记共同查看；“继续整理”会准备补充请求，查看范围后发送。资料自动保存，已有工作台会复用。
- **带走自己的资料**：导出书项目或完整备份，保留原书、笔记、分析和组件内容；书库位置由你选择。

搜索框输入后会先离线查找，支持简繁互搜；连接模型后，普通搜索会纠错、补充同一对象的其他语言写法，相关主题收在结果末尾，点开才查找。右侧的星光 **AI** 按钮会先估算，主动开始后理解你的意思，再阅读全文；能容纳时整本一次，超过当前上下文的保守容量才分批。可以停止、继续，并点击出处回到书中。这会消耗当前AI服务的用量。

想核对 AI 用了哪些资料，可以打开 **请求记录与详情**，展开每次请求和“阅读原文片段”，查看实际发送的文字、页码与返回内容。完整文字只为最近一次同类任务有限保留，开始新任务或重启后，旧任务仍保留次数和操作记录；密钥不显示。

想讨论特定几章时，在对话输入框旁的范围按钮选择 **页码或章节**，确认后再提问。AI读取原文、整理资料和打开组件都沿用这个范围；之后翻页不会悄悄扩大它。生成的资料自动保存，不必每次查看都重新生成。

可以在对话中要求 AI 整理地图、时间轴和行动方向。已有依据的事件与箭头共用同一批资料，日期或路线的推断会另作说明。修改已有资料需要审阅时，本轮先停在审阅处；复杂战役的一次完整整理仍在完善中。

## 第一次打开

1. 点 **导入书籍**，选一本本地书。导入后点封面开始阅读；书库封面的绿色条表示阅读位置。
2. 左上角 **阅读导航** 打开目录、缩略图、书签和查找；底部薄条悬停展开翻页、缩放和纸张工具。
3. 在原文右键写便签、加书签或为当前句子划线；在 **我的笔记** 编辑、分类和保存自己的内容。
4. 想用 AI 时，在 **模型设置** 添加兼容的模型服务，再打开右上角 **伴读与对话**。不接入模型也可以阅读、查找、记笔记。
5. 需要系统分析时，从 **智能阅读** 选择范围，先查看已有成果与待处理部分，再开始。扫描 PDF 可先做 OCR，并对照原页核对识别结果。

## 我们的做法

**原文是依据，你的内容由你掌握。** 原书保留在本地书库，划线和便签的位置另存，不改写原 PDF。笔记正文使用 Markdown；分析与组件保存来源，方便核对、导出和继续使用。

资料详情可以修正人物卡片、事件介绍和关系名称。你改过的字段会保留，其他字段与新出处仍可补充；可注明自己核对了原文、作了推断，或写下个人理解。各组件共用修正后的资料，原文出处单独保留。

**AI 是帮助阅读的工具。** 只有主动使用相关功能时才向你配置的服务发送所需内容。收起回答仍属于当前对话，移入历史才退出自动上下文；历史内容可以手动引用。AI 解释和 OCR 都可能有误，原书始终可对照。

**界面给阅读让出空间。** 常用工具悬浮、按需展开，长说明收进详情，历史内容可折叠。不同组件共享书本资料，避免把同一段内容分别维护成多套副本。

## 安装、备份与说明

支持 macOS 15 及以上，发布包同时支持 Apple Silicon 和 Intel。下载后把 `ReadingBook.app` 放入应用程序目录。当前包尚无 Apple 公证；首次打开可在系统“隐私与安全性”中对该应用单独允许，无需关闭系统安全保护。

书库位置可在设置中查看和更改。换电脑前可导出完整备份；模型密钥留在本机，不放入书籍导出包。加密 PDF 的原文件仍加密，但提取文字、笔记和分析属于普通本地文件，书库本身不提供整库加密。
