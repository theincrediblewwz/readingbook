# ReadingBook · 霜银 / 钴蓝交互稿

用户在 2026-10-16 选定本轮第 1 个样式。它是整个 App 的交互设计稿，不是 macOS 安装包。生产 SwiftUI 源码未在本轮改写。

已启动的本地预览：<http://127.0.0.1:4178/>。页面效果稿：<http://127.0.0.1:4178/design/>。

## 先试这几条完整路径

1. 左侧圆点展开导航；点整行切换页面。顶部书名只切书，顶部服务栏只切已保存的示例服务，不重复列全部工作台。
2. 原文阅读默认打开真实的自编 PDF；翻页、查找、关闭查找、展开/收起伴读。拖动伴读，关闭后从右下恢复。更多菜单里有模型 OCR 演示、文本核对、区域批注与批注恢复。
3. 书库 → 导入示例 PDF → 勾选加密 → 输入错误密码 → 重试 reading。这是解锁流程的设计演示，不读取硬盘图书。
4. 选择《三国演义》→ 时间与地图 → 拖同一轴上的两个端点 → 选事件 → 在同一框下方看详情 → 拖时间框吸附角落或底部中央 → 回到原句。
5. 思维导图 → 单击节点预览 → 拖节点移动 → 从边缘端口连线或右键连线 → 双击打开对应文档。右侧列表可以搜索、收起、关闭和恢复；关系图则明确只读。
6. 我的理解 → 编辑 → 预览真实 KaTeX 公式 → 保存 → 更多加入导图 → 移入回收站 → 恢复 → 导图里原节点和连接回来。脏草稿离页会询问保存、放弃或继续编辑。
7. 与书对话 → 保存菜单选择 Markdown 片段，或选择多条回答合并 → 预览 → 主动保存。普通回答不会自动入库，可下载真实 .md 文件。
8. 插件与组件 → 停用再启用 → 查看已有内容保留 → 可添加只列未添加组件。编辑当前书的类型；数学书示例使用定理/概念，历史书使用事件/人物/地点。
9. 模型设置 → 改名称并保存 → 已知型号点击 Max → 改未知型号看 Max 禁用 → 改回已知型号恢复额度 → 演示测试成功/失败 → 离开未保存表单看草稿保护。
10. 阅读流程 → 预读并选法 → 编辑默认方法或建议新方法 → 逐段执行 → 暂停/继续 → 演示失败重试 → 查看每段概要与插件调用记录。离开流程页暂停本地演示，回页可继续。

## 示例数据与边界

- 所有编辑、删除、恢复、服务配置和阅读回执都留在当前页面内存，刷新后重置。示例输入不写入 macOS App 数据。只有主动点击下载才生成 .md 文件。
- 真实 API Key 输入被禁用；模型连接、OCR、AI 回答、读书分析与插件调用全是明确标识的本地模拟，不发起真实模型或付费请求。Max 采用示例配置上限，不代表实时厂商规格或保证理解能力。
- PDF 是项目自编的 3 页线性代数样本，由浏览器打印排版后以 PDF.js 阅读；Markdown 由 markdown-it 与 KaTeX 渲染。生成效果图中的数学示意有内容差异，不能作为公式正确性的依据。
- 地图地形是生成的布局示意，不是测绘或历史考证证据。时间、地点与人物示例在地图、卡片和图谱中共用对象；页码是本稿 1–3 页的示例映射，不是原著页码。
- 删除操作仅作用于示例数据。书籍与笔记进入回收站，批注在批注面板恢复；移除节点保留文档。没有永久清空入口。

## 实现与复现

从此目录运行 npm install --prefer-offline --no-audit --no-fund，然后 npm run dev -- --host 127.0.0.1 --port 4178 --strictPort。现有预览服务已由本轮启动，不需要重复运行。

npm run build 生成 dist/client。本轮没有公开部署，也没有更改主机代理或联网设置。图标采用 [Phosphor](https://github.com/phosphor-icons/react)，已有书页标记只调整配色；公式与渲染接口参考 [KaTeX](https://katex.org/docs/api.html)。原始提示词和效果图在 ../2026-10-ui-study/screens/。
