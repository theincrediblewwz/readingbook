# 0.15：把悬浮落实到原生布局

2026-10-23。本轮沿用已经选定的霜银/钴蓝效果稿，不重新选择风格。用户提供的两张 Mac 截图存于 evidence-0.15；它们是本次实际问题证据，不把浏览器或设计图当 Mac 修复后的截图。

1. **伴读挤压原文**：ReadingViews 明确预留438pt，故展开必然缩宽。移除这条布局分支；原 PDF 与文本宽度、阅读工具中心不依赖伴读开合。面板可拖动、收起、关闭；提问展开只调整浮层之间的局部避让。
2. **常驻提问框**：默认58pt悬浮入口，点击展开410pt提问卡；缩小保留同一实例中的草稿和范围。伴读的范围菜单与内容菜单分开，去除重复的分段选择和原始乱码预览，出处按需展开；原公式 Markdown 继续由离线渲染器显示。
3. **悬浮卡下没有原页面**：插件/模型成为独立管理呈现状态，原route与内容保留，打开不离开笔记编辑器；关闭回到真实底层，不硬跳原文。模型未保存保护继续；插件“打开”会退出管理层，处理详情转管理会先关闭详情。
4. **原型与原生差距**：使用原先来源图的字号、正文层次、48pt成对操作、24pt留白与描边阴影；伴读 Markdown 增加独立18pt宋体样式。浏览器比较只验证布局/状态，Liquid Glass、PDFKit与系统手势需Mac。
