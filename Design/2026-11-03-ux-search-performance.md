# 记录列表按需准备与查找补齐

0.23.43/build74 候选，2026-11-03。本地修改、Release 编译、54 进程对照和原生界面复核已完成；完整 GitHub CI、发布与安装以本文后续交付回执为准，当前不提前宣称交付完成。

本批直接修复上一轮88项复核中发现的体验缺口，并优化历史、笔记、引用与伴读历史共用的记录列表。没有改变原书、笔记正文、分析、手动文件夹、归档状态或 AI 上下文规则。

## 实际修改

- 折叠片段仅在显示时清理内部来源标记和 Markdown 成对强调符号。正文中的代码、公式、转义字符和变量下划线保留，原文件不改写。复用已有来源解析器处理引用，避免再造一套语法。
- 摘要区分读取中、没有问答、尚未设置模型、空文件夹。没有问答可回到对话，没有模型可直接进入模型设置；不再让人点禁用的“立即整理”。整理、清除和自动整理仍分别保留原有含义。
- 笔记列表展开时只保留列表中的新建入口，收起列表后在正文空态提供新建。空态说明改为日常用语。
- PDF 原生查找通过异步多词查找支持简繁互找。搜“貂蝉”可命中“貂蟬”；结果保留原始字样、UTF-16位置、页码和重复出现处。相同位置去重，清空、改词、关闭仍取消迟到结果，只使用原有一个显示文档。
- 记录浏览器先准备当前列表提供的身份和分组。未提供的身份仍检查重复，较早提问仍参与确定回答标题；不因筛选遗漏完整问答关系。正文片段延迟到行实际出现时生成，离开后取消，换书/换库/内容版本变化时拒绝迟到结果。此临时显示投影不写入书籍数据，不加入AI上下文。

## 性能证据与采用边界

Release 真实 Core 对象，本机54个新进程、3轮交错顺序，每进程丢弃2次预热后取5次。相同确定性输入：大书1484单元、30笔记和1000组问答；小书4组问答和4笔记。旧算法来自0.23.42源文件，仅改类型名以便同进程编译；原始和变换后文件均有哈希。

测量完整目录准备、日期分组和可见片段的进程CPU，不含夹具构造、笔记文件读取、SwiftUI绘制、滚动FPS或整个App内存。展开首组最多显示60行，其他组显示一个收起片段；全收起另测。新旧全部分组、身份、标题、日期、章节完全一致；新按需片段和新完整片段完全一致。原书项目JSON不变，测试不请求真实模型。

## 搜索下一阶段

当前书库已有“AI扩展”：发送检索意图和抽样语言提示，让模型纠错、翻译、给同义词，再由本地查验真实原文。它不接收原书正文，**不是向量语义检索，也不是模型阅读全文**。本轮首先补的是原生PDF简繁能力。

用户新增要求：普通搜索按钮右侧增加带AI标识的独立入口，区分关键词推测与阅读全文查找。阅读全文需逐段覆盖、进度与消耗预估、可停止、原文定位和模型结果查证；不允许抽样后标成已读全书。该功能排在本批性能交付之后，尚未冒称已经实现。普通离线查找始终可用。

技术选择参考：[PDFKit异步多词查找](https://developer.apple.com/documentation/pdfkit/pdfdocument/beginfindstrings(_:withoptions:))、[Foundation正则表达式](https://developer.apple.com/documentation/foundation/nsregularexpression)。复用不可变的已编译表达式，并有并发片段隔离回归。
