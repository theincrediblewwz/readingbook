# 对话、伴读与文件夹收纳 · 0.23.29

本批先解决用户指出的十项机制及界面问题，再继续对话冻结、附件读取与知识库可见行的性能审查。当前本机编译、15组机制检查和原生隔离书库验收通过；完整 GitHub XCTest、通用包与安装版原书验收尚待执行，完成后在本页补齐。此批界面改动不冒称性能提速。

## 用户可见行为

- 空对话中的推荐问题由实际已配置模型结合当前允许阅读的原文生成1–3个，不联网成功就不显示问题；没有固定兜底。一次空对话周期只尝试一次，反复打开面板不重新生成；全部回答被用户收起或归档后可开始下一周期。输入问题时隐藏推荐，清空输入恢复本次缓存。该缓存只在本次应用会话内保存。
- 对话与伴读都有带数量的收起入口。收起只改变显示，回答仍参与当前范围的上下文；“移入历史”把完整问答或伴读收纳到历史文件夹，从下一次提问起退出自动上下文，可恢复，也可在“附加内容”中逐条主动引用。归档用户问题时同时带上其全部回答，避免半个问答残留。
- 笔记、历史对话、对话摘要分别有逻辑文件夹，可新建子文件夹、改名、移动。删除文件夹保留内容，子文件夹上移。笔记可按月份一键收纳未分类项，已经手工分类的笔记保持。收纳不移动原始 Markdown，也不改写聊天、分析或原书。
- 笔记预览不显示宿主内部的 `conversation-message` 来源标记；源文件及编辑模式保留原文。代码块、普通注释、行内内容、引用和列表中的类似文字不被吞掉，Markdown HTML 权限保持关闭。
- 书名使用完整宽度并允许换行，管理按钮内缩；书库、对话更多设置、伴读及文档管理采用宽松的圆角动作浮层。共用轻按钮及菜单增加悬停/按下反馈，样式不增加原布局尺寸。
- 文档详情去掉没有实际差异的“老师伴读/原文考据”切换；真实的对话讲解方式保留在当前页旁的按钮中，选择浮层分别说明两种模式。对象详情仍按其支持的内容保留相应方式。
- “回到原文”会关闭伴读面板并请求回到阅读界面，清理旧对象选择及导航令牌；不再仅修改被工作区覆盖的临时路由。

## 历史与摘要的区别

“历史对话”保存完整问题、回答和出处。放入历史文件夹后，它们不会自动加入下一次提问，主动引用的回答例外。

“对话摘要”（以前称“长对话记忆”）是模型在对话较长时生成的简短回顾，帮助节约上下文。开关控制是否使用这种自动摘要；不等于把所有历史对话重新喂给模型。“查看摘要与原消息”可按文件夹查看已保存摘要，并从来源跳回完整问答。“清除此范围摘要”仅清理可重建的摘要，原问题、回答、笔记及分析保留，之后需要时可重新整理。新界面把说明收到信息按钮和悬停提示中。

## 保护与检查

宿主拥有的收纳元数据是可选字段，旧书无需迁移。仓库 actor 基于最新 canonical 项目提交变更；迟到的 AI 结果、旧编辑页和插件写入不能覆盖手动文件夹或归档操作。自动历史匹配仍执行原书版本、范围、讲解方式、资料版本与来源校验。主动引用最多16条、总计64KiB，不截断内容，也不授予额外原文页权限。

本机15项检查覆盖旧项目解码、整轮收起/归档/恢复、文件夹层级及异常输入、月分类、完整 Unicode 引用、伴读归档、摘要失效、AI/插件保护、仓库重启及并发保存、实际 Provider 请求封装、推荐 JSON 拒绝/截断/预算，以及后台推荐与前台请求独立进行和取消。这里使用实际当前 Core 加本地断言适配器，不能写成完整 XCTest；完整 XCTest 由后续同源 CI 执行。

随产品提交的渲染器检查运行真实 vendored markdown-it 与 renderer.js，15项通过，包括来源位置不漂移、公式和 Unicode 保持、代码及普通注释不误隐藏；另外原生 WebKit 已看到正确预览。新检查加入原有 Markdown CI 步骤，旧原生检查继续保留。

原生 CUA 使用实际当前 AppStore/Core/Views，测试专用模拟传输、两本隔离合成书。验证六组问答收纳/恢复/引用、文件夹 Unicode 改名、摘要归类及来源打开、四条伴读收起/归档、笔记月分类、长书名和浮层；第二遍核对单一计数、输入时推荐缓存、笔记动作不重叠及换书状态隔离。未调用真实模型，不能冒称真实服务质量、物理输入法、Undo 或 FPS 验证。

开工保护记录21个原库文件。本机验收后文件集合及原书、笔记、分析字节保持，所有生产偏好保持；正在运行的原程序仅正常保存了一次伴读面板显隐状态。未用旧备份覆盖现库。证据在 `logs/conversation-workspace-20261031/`，私人保护在 `private-books/conversation-workspace-20261031/`。用户未提交的性能进度文档保持原样，不混入本批提交。
