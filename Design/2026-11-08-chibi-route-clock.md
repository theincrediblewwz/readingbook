# 赤壁：路线时间、重复正文与可信收尾

本批继续本地迭代，不推送 GitHub、不运行云端发布。地图仍复用真实 AI 已保存的22个人物/地点等要素、16个事件、39条关系及14条行动路线。

## 改了什么

| 项目 | 结果与评价 |
| --- | --- |
| 日期筛选后路线消失 | 修复。地图与时间轴都保留时间未明、不可比较的记录，路线用虚线和“时间待定”说明，不假装已匹配日期。明确在范围外的路线仍隐藏；达到128条显示上限时，已知时间的匹配项优先。 |
| 事件日期与路线日期 | 保持分开。刘备移兵樊口的路线在第559页，其关联的伏兵事件在更后面；直接借用事件日期会制造错误。本批没有改写原有时间数据，也未新增日期存储字段。 |
| 重复原文回传 | 有同数据收益。仅在对象/关系查询的 evidence 中，将整段、逐字节一致且本轮已提供的原文换为已有 sourceRef；旧简介、未知片段、局部引文、额外字段与版本 hash 保持。10处重复引文的工具回传从21,175B降至7,593B，少13,582B，约64.1%。这是离线重放真实记录，不能等同于模型整体提速。 |
| 保存与打开状态 | 宿主记录工具来源；同一提案的最新审阅决定取代之前的待审阅状态。组件目录成功不作为打开凭证。早期失败明确记为尝试，保留后续实际成功回执，不把所有失败一并抹掉。 |
| 紧预算收尾 | 修复相关回归发现的问题：先按实际请求体计算可容纳的正文，放不下才收缩，不预先砍半。仅实际发送的片段保留引用权限。 |
| 界面 | 时间未定说明放进小按钮气泡；没有增加新的常驻解释段。真实地图的大圆标记、密度和初始相机范围仍待精修。 |

AI仍收到原本的干净正文；sourceRef只是对已经收到的同一段文字的短引用，不再发第二份原文。保存时软件展开成原来的 unitID/quote，再跑原有逐字与范围校验；共享资料本身不变。请求详情保留实际发给模型的回传，不伪造一个与真实请求不同的展示版本。

## 验证与真实试用

最终 Core 为362个检查方法、3,897条独立断言通过（standalone runner，非本机 XCTest）。共享工作台49项、请求详情43项最终原生回归为routeClock3，五类日志告警均0。Core1发现收尾正文被挤掉的实际问题，修复后旧预算回归保留通过；新增测试一度错误要求旧简介中的引文也消失，现改为核对 evidence 短引用和旧简介分别保持。失败记录保留。

同一真实项目离线对照：全时段14条路线；旧日期过滤逻辑得到0条，新逻辑在建安12年11月20日或20–21日保留14条，全部仍标 unknown；按原文序号600–623筛为9条。没有把关联事件日期填入路线。项目内容、原文、版本与引用权限保持。证据：`logs/chibi-route-clock-20261108/same-data-comparison.json`。

真实调用官方DeepSeek Flash：5次HTTP，含1次推荐问题、4次主问题，报告总token277,227，传输耗时相加21.60秒。问题只要求打开已有工作台并解释时间，未要求重新生成战役。模型沿用原视图，22/16/39的事实资料、两份视图配置、时间资料及原文均未改，正常保存一轮新问答。首次把视图ID误填成组件类型，目录查询后纠正；仍存在一次无效工具调用，不能称流程已最简。

真实回答正确说明“已经打开”和“未新增资料”，也明确当前渲染快照未取得；没有把unsupported说成空地图。原生验收实际切换日期起止到11月20–21日，看见“时间待定14”和说明气泡，点刘备行军路线的“回到原文”显示第559页。不是仅凭模型自述验收。

付费试用使用本批第二候选；之后仅清掉新加的重复说明段、修正提示继承，最终候选用同一冻结资料离线回放，不重复收费。真实宿主另有60条几何诊断，其余四类0，仍须定位；不以自动门槛零告警声称整App所有路径都无告警。

## 测试数据与后续顺序

本次是明确的续接测试：固定上一轮的14条路线基线，新隔离库初始旧对话为0、待审阅为0，没有读取正式私密笔记。它不是从零生成效果测试。今后从零生成只带原文与原书目录，续接才显式带指定资料；每轮记录输入hash、保留项和排除项，规则已写入DEVELOPMENT.md。结束的运行库在核对、归档唯一内容后清理，归档不自动进入下一轮上下文。

下一批优先AI与软件协作：从干净的空隔离库验证赤壁生成效果，简化视图ID与组件类型的打开接口，减少这次真实调用暴露的无效尝试，核对共享事件、路线、时间、出处以及实际保存和打开是否完整。待这层可靠之后，按已选概念图实现新的标记与展示体系；近景细节、中景合并、远景战役分组/密度的计划见 `Design/2026-11-08-map-detail-plan.md`，不能用缩小旧图钉背景代替新设计。真实日期补充、平滑曲线和区域表达继续推进；16类组件性能轮转、几何告警和长期能耗检查继续保留，不把这几项改动当作全部优化已完成。
