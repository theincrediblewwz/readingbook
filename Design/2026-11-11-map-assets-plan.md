# 地图显示素材与真实缩放

理想效果：AI 读已有共享事件与行动后，选择适合的图标素材，用同一工作台显示；例如战役和调查可以用不同图标，不改事实类别。远看同组记录使用分组标识，点击可选具体记录或放大，近看显示独立素材。保存、重开和切时间仍使用同一数据底子。

1. 为 geo.map 增加可选 markerAssets（自由 kind 名到内置素材 ID 的映射）；它属于显示配置，默认缺省兼容旧图。显式映射优先，未映射自定义种类回到中性图标，不按标题硬猜。
2. component_show 可对已有 viewID 按最新 layoutRevision 原位修改各地图元件的映射，不创建重复视图、不重发事实；与已有布局共用一层可恢复备份，重新读取最新书籍保存，保留并发笔记与分析。新建组合也可声明映射。规则只约束素材可用性，不约束书中的自由类别。
3. 扩展通用素材到观测、测量、修复、警示等；素材是程序内置矢量/系统符号，不是每个组件的第二套知识库。合并标记使用分组图标和数量，不拿第一成员的类别代表整组。
4. 对照显式映射与兼容解析的计算成本，确认收益再保留优化；修独立地图与组合地图的事件家族解析不一致。做真实 MapKit 远缩放、展开、放大、成员点击和时间切换检查，不把纯坐标夹具当原生画面通过。
5. 复用已保存赤壁和调查资料，真实官方 Flash 自选素材，不手填 AI 输出；保存输入与失败现场，遵守现有请求节奏、授权与审阅，不动原库。本机集中编译安装与清理；本批不做 GitHub/云 CI/Release。

本轮不编造未知路线、坐标或日期，不做底图淡化。现代地名密度与轴的层级横移继续排后续。
