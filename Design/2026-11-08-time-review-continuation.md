# 本地迭代：审阅续接、时间基准与模型纠错

本批先解决真实赤壁试读暴露的中断问题。工作分支为 `codex/time-review-continuation`；沿用本机 Release ARM64 候选、共享编译缓存。没有创建 GitHub Release/tag、推送或启动完整 CI。最终安装、测试和保护状态以 `logs/time-review-continuation-20261108/final-local-delivery.json` 为准；这个文件生成前不能视为交付完成。

## 实际改动

| 问题 | 现在的处理 | 边界 |
| --- | --- | --- |
| 审阅后“继续”重新提问，丢掉暂停前的准备 | 暂停原来的异步任务；保留同一问题、消息、已读证据、真实工具结果和剩余预算。应用/放弃后，读者点击继续才恢复。 | 仅保留当前进程内任务；退出、取消、换书库、原文改变后不会把旧任务偷偷恢复。重启后已有成果仍在，但不宣称恢复了完整执行现场。 |
| 待审阅任务自身的 busy 状态让审阅按钮禁用 | 专门判断是否可处理当前暂停提案；其他写入、其他 AI 通道和冲突仍保护。 | 不能借此应用不属于当前任务的提案。 |
| 同页序号、章节序号和自编阶段混在同一叙事轴 | 增加可选 `narrativeDomain`，不同基准不互相假装匹配；`source-order` 必须使用引用原文真实 `SourceUnit.order`。 | 无字段的旧数据兼容保留，不迁移重解释；同日“三更、五更”暂保留原话及出处先后，尚未做精确时刻引擎，不编现代时间。 |
| 模型需要猜测内部日期数字；组合页可能假报同步成功 | AI 直接传年月日；宿主计算同一日期轴坐标。组合中的匹配时间组完成实际投影后才返回成功。 | 范围内必须确有该时间体系，换书/不支持的界面不能返回成功。 |
| 引文不匹配只得到一句笼统错误 | 返回具体字段路径、原文 ID、引文预览；候选原文和引用编号仅来自本任务已经提供的文字。模型须核对、重交。 | 不自动改事实、不扩大范围，也不把别页文字静默塞到当前页。 |
| 模型把引用编号写错，或用全角括号导致链接消失 | 原文结果直接带可复制的完整 citation 字段；仅归一化全角引用括号/冒号，再做原有精确 ID 校验。 | 不猜测、补齐或替换 ID；不重写旧回答。 |
| 已收费的回复返回工具后又重复预留输入预算，导致合法本地操作被跳过 | 本地工具回执按上下文窗口算空间；下次真实 HTTP 前仍检查剩余任务额度。 | 没提高生产请求/令牌上限；上游超量用量仍会停止写入。 |
| 一条回复超过隐藏的 8 个工具就整轮失败 | 明示每回复最多 32 个本地工具操作；过量时一次具体反馈，保留未执行草案，让模型分批；再次超量就暂停。 | 工具串行执行，不等于同时发 32 个模型请求；参数、范围、工具授权仍逐项校验。 |
| 任务收尾阶段出现内部 DSML 就立即报错 | 在剩余请求和令牌预算容得下时，也允许一次格式纠正，沿用问题、证据和真实回执，不再开放工具执行。 | 不能无限收费重试；重复失败仍不当作正文保存。最后已无请求/预算时不能凭空追加一轮。 |

## 验证口径

最终本机 316 个测试方法、3,531 条独立断言通过；它链接真实 Release Core 对象，不冒充 macOS 本机 XCTest。47 项原生检查五类运行告警为 0，真实服务结果另按上表评价。原生共享工作台回归保留旧 38 项，再增加 9 项真实界面桥接检查：AppStore 发出日期命令、挂载组合组件完成投影、才收到成功回执，单日只选出相应共享事件；错误书籍/未知时间域拒绝且不改变时钟。这个合成测试与真实模型试读分开统计。

`real3` 的未执行提案与最终全角引用另有零网络原样回放：提案通过 Core 引文校验，不代表通过仓库的全部语义校验或已提交；9 个引用只改标点后均匹配当次实际提供的原文。没有手工补 ID 或事实。

本批没有新的滚动 FPS、整 App 内存或端到端模型提速声明。收益是避免已取得证据/工具工作被错误丢弃，时间基准不混用，纠错信息更具体；真实任务仍多轮准备、首个可用地图等待过长。

## 后续优先顺序

1. 在真实赤壁任务中让核心地图/时间轴较早落盘；精准报告不存在的对象及可复用的真实 ID，减少只读准备和重复锚点操作。任务预算收尾后的可恢复计划仍有缺口，应和进程内审阅续接分开解决。
2. 继续定位长回答追加时的偶发布局等待；确认可重复的触发和收益后再改，不能仅因一次回放正常便判定消失。
3. 数据链走通后实施用户已选的融合地图：左侧独立素材、底部真实时间轴和辅助阶段、点选浮卡、语义图标、标签避让、带出处的曲线/区域。保持 AI 自由组合，不按书名固定模板。
4. 保留 16 类组件的性能轮转、长期驻留/能耗、Intel 首布局和全入口悬停覆盖，不能退回只测 PDF。
